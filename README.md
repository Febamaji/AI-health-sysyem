# AI Health System

## Overview
AI-based healthcare system is designed to provide preliminary health insights and improve accessibility to basic medical guidance.
The system combines a **Django backend** with a **Flutter frontend** to create a cross-platform application capable of processing user inputs and generating meaningful health-related suggestions.
This project was developed as part of an academic initiative to explore how technology and artificial intelligence can support real-world healthcare challenges.

---

## Features

* AI-based health suggestion system
* Cross-platform mobile interface (Flutter)
* Backend processing using Django
* Modular and scalable architecture
* User-friendly interface

---

## Tech Stack

* **Frontend:** Flutter, HTML, CSS, JavaScript
* **Backend:** Pythong Django
* **Languages:** Python, Dart

## Installation & Setup
### Backend (Django)
1. Navigate to backend folder:

   ```
   cd django_part
   ```
2. Create virtual environment:

   ```
   python -m venv venv
   ```
3. Activate environment:

   ```
   venv\Scripts\activate   # Windows
   ```
4. Install dependencies:

   ```
   pip install -r requirements.txt
   ```
5. Run server:

   ```
   python manage.py runserver
   ```

---

### Frontend (Flutter)
1. Navigate to frontend folder:

   ```
   cd untitled
   ```
2. Install dependencies:

   ```
   flutter pub get
   ```
3. Run application:

   ```
   flutter run
   ```
